# 🏛️ Heritage Preservation Portal

A modern, responsive web application built using **React** and **Vite** to showcase India's rich cultural heritage and historical monuments. The project aims to educate users about famous monuments, their history, architecture, and cultural significance through an attractive and user-friendly interface.

---

## 🌐 Live Demo

🔗 https://heritage-preservation-portal.vercel.app

---

## 📖 Project Overview

The **Heritage Preservation Portal** is a web application designed to preserve and promote India's cultural and historical heritage. Users can explore detailed information about iconic monuments, learn about their history, and understand their importance in Indian culture.

This project demonstrates modern frontend development practices using React, component-based architecture, routing, responsive design, and cloud deployment.

- Promote awareness of Indian heritage.

## 🚀 Installation

Clone the repository:

```bash
git clone https://github.com/Dhwnit27/heritage-preservation-portal.git
```

Navigate into the project:

```bash
cd heritage-preservation-portal/client
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```

Preview production build:

```bash
npm run preview
```
